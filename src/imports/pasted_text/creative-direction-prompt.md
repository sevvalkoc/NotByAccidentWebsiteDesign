DESIGN PRINCIPLE

Beauty comes from judgement.

Not decoration.

If something is beautiful because

it moves,

remove the movement.

If something is beautiful because

it glows,

remove the glow.

If something is beautiful because

it is oversized,

make it normal.

If something remains beautiful

after removing everything unnecessary,

keep it.

TYPOGRAPHY

Typography is the architecture.

Not decoration.

Do not make headlines enormous simply because modern websites do.

Use restraint.

Beautiful proportions.

Elegant rhythm.

Editorial line lengths.

Intelligent hierarchy.

QUALITY CONTROL

Before finishing ask:

Would this win because it is beautiful?

Or because it is unusual?

If unusual,

remove the novelty.

Would someone save screenshots of this site?

Would another creative director wish they had designed it?

Would a founder trust this company with a seven-figure rebrand?

Would someone spend twenty minutes reading the blog even if they never became a client?

Does this feel designed,

or merely styled?

If it feels styled,

redesign it.
